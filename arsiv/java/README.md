# Uzay Savaşı 2D — Java sürümü (arşiv)

Oyunun ilk masaüstü sürümü (Java Swing). **Artık geliştirilmiyor**; güncel oyun deponun kökündeki web sürümüdür.

Çalıştırmak için (Java 17+ ve Maven gerekir), bu klasörde:

```
mvn package
java -cp target/classes uzaysavasi.Main
```

Kayıtlar `~/.uzay_savasi_2d` klasöründe tutulur.
